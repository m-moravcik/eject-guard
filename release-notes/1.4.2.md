Backup progress shows for every Time Machine backup, to a plugged-in disk or a network share, whether or not you ticked it and even with guarding off. Guarding still only decides what gets ejected or stopped before a meeting.

The percentage now matches the Time Machine menu bar item: the same figure, to one decimal, and only while Time Machine is copying. Before, the app showed the copy alone, so 13.5% in the system menu read as 3% here.

A backup already running when the app starts shows within seconds instead of after the first poll.
