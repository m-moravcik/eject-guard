A disk you do not guard is now forgotten a week after you unplug it. A volume that only existed for a moment, such as one made while formatting a disk, used to stay in the list until you hid it. Guarded disks and Time Machine disks are never forgotten, and a forgotten disk is listed again the next time you plug it in.

A disk that became a Time Machine disk after the app first saw it is no longer listed twice. The app now reads the link between the two from Time Machine's own settings, so it holds while the disk is unplugged, and a disk already listed twice is merged back into one row without losing its guard.

Signed with Developer ID, notarized and stapled. Requires macOS 14.
