The command line tool now comes with the app. Open Settings > Advanced and click Install… to put `eject-guard` on your PATH, then wire up your own triggers: `eject-guard --eject-now` at the end of the workday, from a Focus mode, a Stream Deck button or a Shortcuts Run Shell Script action. It updates together with the app.

While Eject Guard is running, the tool asks the app to act, so the popover shows the change at once and two passes never race for the same disk. New commands mirror the menu: `--pause MINUTES`, `--resume`, `--skip-next`, `--stop-backup`, plus `--json` for scripts and `--version`.

Eject Guard adds actions to the Shortcuts app: Eject Guarded Disks, Pause Eject Guard, Resume Eject Guard, Skip Next Meeting and Stop Time Machine Backup. Run them from a personal automation, such as at 6 pm on weekdays or when a Focus mode turns on, or ask Siri to pause Eject Guard.

Settings has a new Advanced tab with the command line tool, Open log, Show config and Copy diagnostics. Eject Guard still sends nothing anywhere; to report a bug, Copy diagnostics puts the app's state and recent log on the clipboard, with meeting titles and disk names left out, for you to paste into an issue.

Eject Guard now also speaks Spanish and French.

While Time Machine backs up, the menu bar tooltip now says which disk it is backing up to, in every language; it used to read as if that disk were the one being backed up.
