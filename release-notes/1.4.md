Eject Guard now looks after Time Machine backups to a NAS as well. A network Time Machine destination shows up in the list next to your disks. Tick it, and a backup running to it is stopped before the meeting, when the Mac goes to sleep, or with ⌘E, so you never walk off the network in the middle of a write. Nothing is ejected: there is no cable to pull. Plain network shares are not listed.

Each disk now says how it is connected: USB, Thunderbolt, SD card or network, and its icon shows whether it is a plain disk, a Time Machine disk or a network destination.

The command line tool lists network destinations and reports a stopped backup.

Signed with Developer ID, notarized and stapled. Requires macOS 14.
